【0.10.0】

**新增**
- 插件市场：在「设置 → 插件」里可以安装插件。

**优化**
- 「全部历史」中在热力图上拖选几天放大时，加入了过渡动画。

**修改**
- 切换界面语言后，默认分类和大类的名字不再跟着变，需要时可以手动改名。
- 分类和大类改名后不再同步到其他设备；新建的分类仍会同步。

**修复**
- 修复系统语言为繁体中文、葡萄牙语或西班牙语时，刚启动时托盘菜单显示为简体中文的问题。
- 修复非简体中文界面下，在 AI 对话里按分类名提问可能查不到数据、回答里出现简体中文分类名的问题。
- 修复非简体中文界面下，给默认分类改名时，输入框里显示简体中文名的问题。

【0.10.0】

**New**
- Plugin market: you can install plugins in Settings → Plugins.

**Improved**
- In "All time", zooming in by dragging across days on the heatmap is now animated.

**Changed**
- Default category and super-category names no longer change when you switch the UI language. You can rename them if needed.
- Renaming a category or super-category no longer syncs to your other devices. New categories still sync.

**Fixed**
- Fixed the tray menu showing Simplified Chinese right after startup when the system language was Traditional Chinese, Portuguese or Spanish.
- Fixed AI chat when the UI language was not Simplified Chinese: asking about a category by name could find no data, and answers could show the category's Simplified Chinese name.
- Fixed an issue where the text field showed a default category's Simplified Chinese name when renaming it in a non-Simplified Chinese interface.

【0.10.0】

**新機能**
- プラグインマーケット：「設定 → プラグイン」でプラグインをインストールできます。

**改善**
- 「全履歴」でヒートマップの数日をドラッグして拡大するとき、アニメーションが付くようになりました。

**変更**
- 表示言語を切り替えても、デフォルトの分類と大分類の名前は変わらなくなりました。必要なら名前を変更できます。
- 分類と大分類の名前を変更しても、他のデバイスには同期されなくなりました。新しく作成した分類は引き続き同期されます。

**修正**
- システム言語が繁体字中国語・ポルトガル語・スペイン語のとき、起動直後のトレイメニューが簡体字中国語で表示される問題を修正しました。
- 表示言語が簡体字中国語以外のとき、AI チャットでカテゴリ名を指定して質問するとデータが見つからないことがあり、回答に簡体字中国語のカテゴリ名が出ることがある問題を修正しました。
- 簡体字中国語以外の表示言語でデフォルトのカテゴリを変更する際、入力欄に簡体字中国語の名前が表示される問題を修正しました。

【0.10.0】

**Novidades**
- Loja de plugins: agora você pode instalar plugins em Ajustes → Plugins.

**Melhorias**
- Em "Todo o histórico", ampliar arrastando sobre alguns dias no mapa de calor agora tem animação.

**Alterações**
- Os nomes das categorias e supercategorias padrão não mudam mais ao trocar o idioma da interface. Você pode renomeá-los se precisar.
- Ao renomear uma categoria ou supercategoria, o nome não é mais sincronizado com seus outros dispositivos. As categorias novas continuam sendo sincronizadas.

**Correções**
- Corrigimos o menu da bandeja que aparecia em chinês simplificado logo após iniciar quando o idioma do sistema era chinês tradicional, português ou espanhol.
- Corrigimos o chat de IA quando o idioma da interface não era chinês simplificado: perguntas sobre uma categoria pelo nome podiam não encontrar dados, e as respostas podiam mostrar o nome da categoria em chinês simplificado.
- Corrigimos o problema em que o campo de texto exibia o nome em chinês simplificado ao renomear uma categoria padrão com a interface em um idioma diferente do chinês simplificado.

【0.10.0】

**Novedades**
- Tienda de plugins: ahora puedes instalar plugins en Ajustes → Plugins.

**Mejoras**

- Corregimos el chat de IA cuando el idioma de la interfaz no era chino simplificado: las preguntas sobre una categoría por su nombre podían no encontrar datos, y las respuestas podían mostrar el nombre de la categoría en chino simplificado.
- Corregimos el problema por el que el campo de texto mostraba el nombre en chino simplificado al renombrar una categoría predeterminada con la interfaz en un idioma distinto del chino simplificado.
