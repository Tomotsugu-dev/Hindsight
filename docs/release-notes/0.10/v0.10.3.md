【0.10.3】

**新增**
- 「设置 - 插件」的插件市场显示插件下载总数，URL 跳转仓库的功能。
- 新增插件市场的搜索功能。
- 新增插件市场筛选官方插件，按下载数量排序的功能。
- 插件市场里，点插件的仓库名，会在浏览器里打开它的 GitHub 仓库。
- 「设置 - 外观 - 自定义主题」新增「获取主题」按钮，在浏览器里打开主题网站，主题可以先试用再下载。

**修改**
- 一些 小的 UI 修改与优化。

【0.10.3】

**New**
- The plugin market in Settings - Plugins shows each plugin's total downloads, and a URL that takes you to its repository.
- The plugin market now has search.
- The plugin market can now show only official plugins, and sort plugins by download count.
- In the plugin market, click a plugin's repository name to open its GitHub repository in your browser.
- Settings - Appearance - Custom themes has a new Get themes button. It opens the theme website in your browser, where you can try a theme before you download it.

**Changed**
- Some small UI changes and improvements.

【0.10.3】

**Novidades**
- A loja de plugins em "Ajustes - Plugins" mostra o total de downloads de cada plugin e uma URL que leva ao repositório.
