【0.11.5】

**新增**
- 「分类 · 管理分类」可以拖拽调整层级：把分类拖到两个大类之间，升为新的大类；把大类拖到另一个大类上，并入其中。

**修改**
- 拖拽排序时用一条插入线标出落点，其他行不再跟着挪动。

**修复**
- 修复了：Windows 的「文本大小」调大后，主窗口内容被挤压、按钮被裁掉的问题。

【0.11.5】

**新增**
- 「分類 · 管理分類」可以拖曳調整層級：把分類拖到兩個大類之間，升為新的大類；把大類拖到另一個大類上，併入其中。

**修改**
- 拖曳排序時用一條插入線標出落點，其他列不再跟著移動。

**修正**
- 修正了：Windows 的「文字大小」調大後，主視窗內容被擠壓、按鈕被裁掉的問題。

【0.11.5】

**New**
- In Categories · Manage categories, drag a category between two super-categories to make it a new super-category, or drag a super-category onto another to merge it in.

**Changed**
- Dragging to sort now shows a line where the item will land, and the other rows stay in place.

**Fixed**
- Fixed: with a larger Text size in Windows, the main window's content was squeezed and buttons were cut off.

【0.11.5】

**新機能**
- 「分類 · カテゴリ管理」で、カテゴリを 2 つの大分類のあいだにドラッグすると新しい大分類になり、大分類を別の大分類にドラッグすると統合できます。

**変更**
- ドラッグでの並べ替えは、入る位置を線で示すようになり、ほかの行は動きません。

**修正**
- Windows の「テキストのサイズ」を大きくすると、メインウィンドウの内容が詰まり、ボタンが切れてしまう問題を修正しました。

【0.11.5】

**Novidades**
- Em Categorias · Gerenciar categorias, arraste uma categoria para entre duas supercategorias para criar uma nova, ou arraste uma supercategoria para cima de outra para mesclá-la.

**Alterações**
- Ao arrastar para reordenar, uma linha mostra onde o item vai ficar, e as outras linhas não se movem.

**Correções**
- Corrigido: com o Tamanho do texto do Windows aumentado, o conteúdo da janela principal ficava espremido e os botões apareciam cortados.

【0.11.5】

**Novedades**
- En Categorías · Gestionar categorías, arrastra una categoría entre dos supercategorías para crear una nueva, o arrastra una supercategoría sobre otra para combinarla.

**Cambios**
- Al arrastrar para reordenar, una línea muestra dónde quedará el elemento, y las demás filas no se mueven.

**Correcciones**
- Corregido: con el Tamaño del texto de Windows aumentado, el contenido de la ventana principal quedaba apretado y los botones aparecían cortados.
