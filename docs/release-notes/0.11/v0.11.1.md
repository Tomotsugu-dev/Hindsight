【0.11.1】

**新增**
- 日统计、周统计、月统计的「时段」视图可以按大类查看了：点图例最左边的「大类 / 小类」切换。

**修复**
- 修复 Windows 开机后第一次打开 Hindsight，所有分类有可能显示为灰色的问题。
- 修复深色模式下「占比」视图里几处底色变浅、文字看不清的问题。

【0.11.1】

**New**
- The Hours view on the Daily, Weekly and Monthly pages can now show super-categories: use the "Super-categories / Categories" switch at the start of the legend.
- On Windows, plugins can now float on the screen like the Dynamic Island.

**Fixed**
- Fixed an issue on Windows where all categories could show as gray the first time you opened Hindsight after starting the computer.
- Fixed parts of the Share view that turned light in dark mode, which made their text hard to read.
