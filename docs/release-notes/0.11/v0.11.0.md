【0.11.0】

**新增**
- 支持 Linux，目前只支持基础功能。
- 支持的系统：Ubuntu 22.04 及以上、Debian 12 及以上、Fedora，提供 .deb 和 .rpm 安装包（仅 x86_64）。
- 支持的桌面：X11 会话里的任何桌面，如 KDE Plasma、GNOME；Wayland 会话里只支持 GNOME 46 – 51。
- Linux 上暂时读不到浏览器的网址，所以应用详情的「按网站」没有数据；默认的隐私设置下，浏览器窗口也不截图。

**修复**
- 修复选项很多的下拉菜单（如插件的版本列表）超出窗口、后面的选项看不到的问题。现在菜单最多显示 8 项，其余可以滚动查看。

【0.11.0】

**New**
- Linux support. Only the basic features work for now.
- Systems: Ubuntu 22.04 or later, Debian 12 or later, and Fedora, with .deb and .rpm packages (x86_64 only).
- Desktops: any desktop in an X11 session, such as KDE Plasma or GNOME. In a Wayland session, only GNOME 46–51.
- On Linux, Hindsight cannot read the browser's address yet, so "By site" in app details has no data. With the default privacy settings, it also takes no screenshots of browser windows.

**Fixed**
- Fixed picker menus with many options, such as a plugin's versions, running past the edge of the window and hiding the last options. Menus now show at most eight options and scroll the rest.

【0.11.0】

**新機能**
- Linux に対応しました。今のところ基本的な機能のみ使えます。
- 対応システム：Ubuntu 22.04 以降、Debian 12 以降、Fedora。.deb と .rpm パッケージを用意しています（x86_64 のみ）。

- 選択肢が多いメニュー（プラグインのバージョン一覧など）がウィンドウからはみ出し、最後の選択肢が見えなくなる問題を修正しました。メニューには最大 8 項目を表示し、残りはスクロールで表示します。
