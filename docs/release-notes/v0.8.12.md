【0.8.12】
- 对话消息新增操作:复制、重新回答、重新提问;编辑已发出的提问会生成会话分支,不同版本可来回切换
- AI 设置新增「定时计划」:自动总结与自动 OCR 各自在 24 小时轴上设定每日执行时间,可用加减号添加或移除多个时间点,轴上铺有与时段划分一致的配色
- 自动总结改为到点生成当天的日报,前一天缺报会自动补齐;设多个时间点时,每个点都会刷新当天日报(后面的覆盖前面的)
- 自动 OCR:每天到设定时间自动识别堆积的截图,不依赖常驻 OCR;任务开始时会弹系统通知
- 识别进行中,任意页面顶部都会出现进度横幅,可随时停止;"截图尚未进入索引"的提示只在对话页显示
- 对话输入框新增思考模式选择,可选档位随当前服务商变化;回答下方会显示本轮思考消耗的 token 与用时
- 本地模型里不支持工具调用的不再出现在对话模型列表,模型页用图标标出 Tool-use 等能力
- 云端 API 修复:较新的 OpenAI 模型此前完全无法使用、Kimi 服务商选中后会被重置;模型 ID 列表只列文本模型并把精确匹配排在最前,请求参数不被服务商接受时会自动调整后重试

【0.8.12】
- Chat messages gain actions: copy, answer again, ask again; editing a sent question creates a conversation branch you can switch between
- AI Settings gains a Schedules section: Auto summary and Auto OCR each pick daily run times on a 24-hour axis — add or remove multiple time points with plus/minus, with the axis tinted to match your day segments
- Auto summary now generates today's report at the set time and fills in a missing previous day; with multiple time points, each one refreshes today's report (later points overwrite earlier ones)
- Auto OCR reads the screenshot backlog at the set times each day, independent of Resident OCR; a system notification appears when a run starts
- While recognition is running, a progress banner appears at the top of every page with a stop button; the "screenshots not yet indexed" prompt now only shows on the Chat page
- The chat composer gains a thinking-mode picker whose levels follow the current provider; each answer now shows the thinking tokens it spent and how long the turn took
- Local models without tool-calling support no longer show up in the chat model list, and the Models page marks capabilities such as Tool-use with icons
- Cloud API fixes: newer OpenAI models were completely unusable and picking the Kimi provider silently reverted; the model ID list now shows text models only with exact matches first, and a request auto-adjusts and retries when a provider rejects one of its parameters

【0.8.12】
- チャットメッセージに操作を追加:コピー、再回答、再質問。送信済みの質問を編集すると会話が分岐し、バージョンを切り替えられます
- AI 設定に「定時スケジュール」を追加:自動サマリーと自動 OCR をそれぞれ 24 時間軸で設定でき、プラス/マイナスで時刻を複数追加・削除できます。軸には時間帯区分と同じ配色が敷かれます
- 自動サマリーは設定時刻に当日の日報を生成するようになり、前日分が未生成なら補完します。複数の時刻を設定すると、各時刻で当日の日報を更新します(後の時刻が上書き)
- 自動 OCR:毎日設定時刻に未処理スクリーンショットの積み残しを自動認識します。常駐 OCR とは独立して動作し、開始時にシステム通知が表示されます
- 認識の実行中は、どのページでも上部に進行状況バナーが表示され、いつでも停止できます。「未インデックス」の案内はチャットページのみに表示されます
- チャット入力欄に思考モードの選択を追加しました。選べる段階は現在のサービスに応じて変わり、回答の下に思考で使ったトークン数と所要時間を表示します
- ツール呼び出しに対応しないローカルモデルはチャットのモデル一覧に表示されなくなり、モデルページでは Tool-use などの能力をアイコンで示します
- クラウド API の修正:新しめの OpenAI モデルが全く使えない、Kimi を選んでも元に戻る問題を修正しました。モデル ID 一覧はテキストモデルのみを表示し完全一致を先頭に並べ、パラメータが拒否された場合は自動で調整して再試行します

【0.8.12】
- Mensagens do chat ganham ações: copiar, responder novamente, perguntar novamente; editar uma pergunta enviada cria uma ramificação da conversa entre versões alternáveis
- As Configurações de IA ganham a seção Agendamentos: Resumo automático e OCR automático definem horários diários em um eixo de 24 horas — adicione ou remova vários horários com mais/menos, com o eixo colorido como os segmentos do dia
- O resumo automático agora gera o relatório de hoje no horário definido e preenche um dia anterior faltante; com vários horários, cada um atualiza o relatório de hoje (os posteriores sobrescrevem)
- OCR automático: reconhece o acúmulo de capturas nos horários definidos de cada dia, independente do OCR residente; uma notificação do sistema aparece ao iniciar
- Durante o reconhecimento, um banner de progresso aparece no topo de qualquer página com botão de parar; o aviso de "capturas ainda não indexadas" agora só aparece na página de Conversa
- O campo de mensagem ganha um seletor de modo de raciocínio cujos níveis acompanham o provedor atual; cada resposta mostra os tokens de raciocínio gastos e o tempo do turno
- Modelos locais sem suporte a chamada de ferramentas não aparecem mais na lista de modelos do chat, e a página de Modelos marca capacidades como Tool-use com ícones
- Correções de API na nuvem: modelos mais novos da OpenAI estavam inutilizáveis e a escolha do provedor Kimi era revertida sozinha; a lista de IDs mostra apenas modelos de texto priorizando correspondências exatas, e a requisição se ajusta e tenta de novo quando um provedor rejeita algum parâmetro
