【0.10.2】

**新增**
- 新增自定义主题：在「设置 - 外观 - 自定义主题」里导入主题文件，可以改配色、明暗和页面布局。

**优化**
- 插件市场里，插件的介绍改为按界面语言显示。
- 优化了「日统计」「周统计」「月统计」占比视图中，鼠标停在应用上时的后端查询效率。

**New**
- New custom themes: import a theme file in Settings - Appearance - Custom themes to change the colors, light or dark, and the page layout.

- The plugin market shows each plugin's description in the interface language.

【0.10.2】

**Novedades**
- Nuevos temas personalizados: importa un archivo de tema en «Ajustes - Apariencia - Temas personalizados» para cambiar los colores, el modo claro u oscuro y el diseño de la página.
