**新增**
- 新增自定义主题：在「设置 - 外观 - 自定义主题」里导入主题文件，可以改配色、明暗和页面布局。

**优化**
- 应用详情的「按网站」列表里，每个网站前面显示它的图标（需开启「自动下载网站图标」）。
- 优化了「日统计」「周统计」「月统计」占比视图中，鼠标停在应用上时的后端查询效率。

**修改**
- 应用详情的「按网站」列表默认全部收起，不再自动展开用时最长的网站。

**修复**
- 修复插件市场里，插件的介绍没有按界面语言显示的问题。

【0.10.2】

**New**
- New custom themes: import a theme file in Settings - Appearance - Custom themes to change the colors, light or dark, and the page layout.

**Improved**
- In app details, each website under "By site" shows its icon. This needs "Automatically download website icons" to be on.
- In the Share view of Daily, Weekly and Monthly, hovering over an app now runs a more efficient backend query.

**Changed**
- In app details, all websites under "By site" start closed. The website with the most time no longer opens by itself.

**Fixed**
- Fixed the plugin market not showing each plugin's description in the interface language.

【0.10.2】

**新機能**
- カスタムテーマを追加しました。「設定 - 外観 - カスタムテーマ」でテーマファイルを読み込むと、配色、ライト / ダーク、ページのレイアウトを変えられます。

**改善**
- アプリの詳細の「サイト別」で、各サイトのアイコンを表示するようにしました（「サイトアイコンを自動ダウンロード」がオンのとき）。
- 「日次」「週次」「月次」の割合表示で、アプリにマウスを重ねたときのバックエンドでのデータ取得を効率化しました。

**変更**
- アプリの詳細の「サイト別」は、最初はすべて閉じた状態で表示するようにしました。使用時間がいちばん長いサイトが自動で開くことはなくなりました。

**修正**
- プラグインマーケットで、プラグインの説明が表示言語で表示されない問題を修正しました。

【0.10.2】

**Novedades**

- Corregimos que la tienda de plugins no mostrara la descripción de cada plugin en el idioma de la interfaz.
