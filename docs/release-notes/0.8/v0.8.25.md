【0.8.25】
- 对于开启多设备同步的用户：应用的可执行文件路径不再跨设备同步。同系统的多台设备把同一应用装在不同位置时，设备之间此前会互相覆盖这条记录，导致该应用的图标显示不出来
- 在 Windows 上可执行文件路径通常包含用户名，这类信息现在不再上传到云端

<!-- en -->
【0.8.25】
- If you have multi-device sync enabled: app executable paths no longer sync between devices. When several computers on the same OS have the same app installed in different places, the devices used to overwrite each other's record, and the app's icon could not be displayed
- On Windows, an executable path usually contains the user name; this information no longer goes to the cloud
