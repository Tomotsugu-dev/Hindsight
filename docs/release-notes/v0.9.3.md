【0.9.3】

**Changed**
- Some setting names and descriptions are now easier to understand.
- The notification when Scheduled OCR starts now reads "Scheduled OCR started", matching the setting's name, and uses the operating system language.
- Switching items in the sidebar now slides more gently, without a visible bounce.

- Fixed missing notifications when Scheduled OCR started while the window was closed.

- Fixed sync getting stuck until the app was restarted when the cloud server stopped responding.
