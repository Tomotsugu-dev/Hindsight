【0.10.1】

**新增**
- 插件发通知时可以播放系统提示音。安装插件时，这项权限会单独列出来。
- 新增「留白扁平」外观：纯白底色、宽松留白，以细线划分内容。在「设置 - 外观」里切换。

**优化**
- 优化了「日统计」「周统计」「月统计」的数据显示速度。
- 优化了「周统计」「月统计」「全部历史」的后端查询效率。

【0.10.1】

**New**
- Plugins can play the system alert sound with a notification. This permission is listed separately when you install a plugin.
- New "Airy flat" look: a white background, generous spacing and thin dividers. Pick it in Settings - Appearance.

**Improved**
- Daily, Weekly and Monthly now show their data faster.
- Weekly, Monthly and All time now run their backend queries faster.

**Novedades**
