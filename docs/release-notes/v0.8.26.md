【0.8.26】
- 修复了「清空数据」没有清空截图文字（OCR）数据库的漏洞。
- 修复了「清空数据」可能会清空其它设备的应用分组设置的漏洞。
- 修复了「从云端移除本设备」之后由于账户仍然处于登录状态，会将本地数据再次推送到云端的漏洞。
- 新增功能：设置 → 数据的「当前占用」中现在新增展示截图文字（OCR）数据库占用的磁盘空间
