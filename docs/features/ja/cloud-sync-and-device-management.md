## 概要

クラウド同期でアクティビティ記録やアプリ設定を複数のデバイス間で共有し、異なる OS やデバイスの使用記録をまとめられます。

## 対応プロトコル

現在、次のクラウド同期プロトコルに対応しています。

- **WebDAV**：WebDAV サーバーを通じて同期します。自分で運用するサーバーや、Nextcloud、Nutstore（坚果云）などのサービスを利用できます。
- **Google Drive**：Google Drive を通じて同期します。Google アカウントで利用できます。

## 同期するデータ

| データ | 同期 | 説明 |
| --- | --- | --- |
| アクティビティ記録（アプリ、ウィンドウタイトル、時刻、サイトのドメイン） | ✅同期 | - |
| アプリ設定（アプリ・サイトの分類ルール） | ✅同期 | - |
| AI サマリー、チャット履歴、画面メモリ全文 | ⚙️任意 | 設定で個別に有効化 |
| スクリーンショット画像 | ❌同期しない | 常にローカルにのみ保存 |

## 初期設定

| 項目 | 初期設定 | 説明 |
| --- | --- | --- |
| クラウド同期 | オフ | 設定が必要 |
| 同期の間隔 | 約 5 分 | バックグラウンドで 300 秒ごとに送受信。「今すぐ同期」で手動実行も可能 |
| AI サマリーのテキスト | オフ | 「AI サマリーのテキスト」を有効にすると同期 |
| チャット履歴 | オフ | 「チャット履歴」を有効にすると同期 |
| 画面メモリ全文 | オフ | 「画面メモリ全文」を有効にすると認識された文字を同期 |
| スクリーンショット画像 | 同期しない | 常にローカルにのみ保存 |
