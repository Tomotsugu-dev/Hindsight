<h1 align="center">Hindsight 全機能ガイド</h1>

<p align="center">
  <a href="https://hindsight.kyosweb.com">公式サイト</a> ·
  <a href="https://github.com/Tomotsugu-dev/Hindsight/releases/latest">ダウンロード</a> ·
  <a href="https://github.com/Tomotsugu-dev/Hindsight">GitHub</a>
</p>

Hindsight はパソコンの使用状況を記録するツールです。使用したアプリやウィンドウをバックグラウンドで記録し、日次・週次・月次の統計を表示します。必要に応じて、スクリーンショット内の文字検索、AI による要約やアクティビティ検索、複数デバイス間の同期も利用できます。
