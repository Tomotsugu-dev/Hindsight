## 機能概要

データの保持期間を設定したり、統計をさまざまな形式にエクスポートして分析に使ったりできます。

## データのエクスポート

日次・週次・月次の統計をファイルに書き出せます。「設定 → データ → 使用データをエクスポート」で期間と形式を選びます。HTML、Markdown、Excel、JSON に対応しています。

## データの整理

- **自動削除**：保持期間を過ぎたスクリーンショットを自動削除します。アクティビティ記録と認識された画面テキストは自動削除しません。
- **スクリーンショットを削除**：保存済みの画像をすべて削除します。アクティビティ記録と認識された画面テキストは残ります。
- **データを削除**：ローカルデータベースのアクティビティ記録、AI サマリー、画面テキスト、チャット履歴を削除します。アプリ設定（分類、アプリのグループ、各種設定）は残ります。クラウド上のデータには影響しません。
- **このデバイスを削除**：ローカルデータを削除し、クラウドからもこのデバイスの記録を削除します。デバイスを使わなくなった場合に利用できます。

## 初期設定

| 項目 | 初期設定 | 説明 |
| --- | --- | --- |
| データの保存先 | OS のアプリデータディレクトリ内の `Hindsight` フォルダー | macOS：`~/Library/Application Support/Hindsight`、Windows：`%APPDATA%\Hindsight` |
| スクリーンショットの保存先 | データの保存先にある `screenshots` フォルダー | - |
| AI モデルの保存先 | データの保存先にある `ai/models` フォルダー | - |
| スクリーンショット保持 | 7 日 | 1–120 日に設定可能。期限を過ぎた画像ファイルは自動削除 |
| アクティビティ記録の保持 | 無期限 | 自動削除しない |
