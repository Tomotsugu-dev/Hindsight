## Windowsでの実測結果

| 設定 | メインウィンドウ表示中 | メインウィンドウを閉じた状態 |
| --- | --- | --- |
| スクリーンショット・常時OCRともにオフ（初期設定） | メモリ約145 MB、CPU約2.0% | メモリ約25 MB、CPU約0.3% |
| スクリーンショットのみオン | メモリ約145 MB、CPU約3.5% | メモリ約26 MB、CPU約2.4% |
| スクリーンショットと常時OCRをオン | メモリ約400 MB、CPU約4.1% | メモリ約280 MB、CPU約3.0% |

> 1. メモリ使用量は、タスク マネージャーの「メモリ」列と同じ指標（プライベート ワーキング セット）です。
> 2. CPU使用率は平均値です。100%は1コアを使い切った状態を表します。
> 3. Windowsではプロセスごとの消費電力を取得できないため、電力は測定していません。
> 4. GPUはほとんど使用されておらず、使用率は合計で0.3%未満です。
> 5. Windows版では、メインウィンドウを閉じるとWebプロセスを終了せずに一時停止します。メモリ使用量は約30秒で130 MB前後から10 MB未満に下がります。

## macOSでの実測結果

| 設定 | メインウィンドウ表示中 | メインウィンドウを閉じた状態 |
| --- | --- | --- |
| スクリーンショット・常時OCRともにオフ（初期設定） | メモリ約180 MB、CPU約3.6%、電力約5 mW | メモリ約40 MB、CPU約0.2%、電力1 mW未満 |
| スクリーンショットのみオン | メモリ約190 MB、CPU約3.9%、電力約30 mW | メモリ約50 MB、CPU約0.7%、電力約30 mW |
| スクリーンショットと常時OCRをオン | メモリ約260 MB、CPU約4.5%、電力約35 mW | メモリ約110 MB、CPU約1.5%、電力約40 mW |

> 1. CPU使用率は平均値です。100%は1コアを使い切った状態を表します。
> 2. 電力はmacOSがプロセスごとに推定した平均値です。設定間の比較に使えますが、実際の消費電力とは異なります。
> 3. GPUはほとんど使用されておらず、使用率は合計で0.1%未満です。

## 測定条件

- Windows：デスクトップPC、AMD Ryzen 9 9950X3D、メモリ64 GB、Windows 11 Pro、Hindsight 0.9.4、スクリーンショット間隔30秒。テスト中はメモ帳に自動で文字を入力し、メモ帳、エクスプローラー、電卓を切り替えました。
- macOS：MacBook Air、Apple M5、メモリ24 GB、macOS 27、電源アダプタ接続、Hindsight 0.9.3、スクリーンショット間隔30秒。テスト中はテキストエディットに自動で文字を入力しました。
- アプリは10～25秒ごとに切り替えました。
- 各設定で最初に2分間動作させ、その後5分間測定しました。
- 設定を変える前に毎回Hindsightを再起動しました。長時間連続で動作させると、メモリ使用量は表より増えることがあります。

数値は今回使用した端末と使用状況での結果です。別のPCでは異なる場合があります。

### Windowsのデータ

#### 設定ごとの測定

| 設定 | メインウィンドウ | メモリ 平均 / 最大 | CPU 平均 / 最大 | GPU | 撮影数 | 認識数 |

| スクリーンショット・常時OCRともにオフ（初期設定） | 🟠 非表示 | 25 / 28 MB | 0.3% / 8% | 0 | 0 | 0 |
| スクリーンショットのみオン | 🟠 非表示 | 26 / 38 MB | 2.4% / 34% | 0 | 16枚 | 0 |
| スクリーンショットと常時OCRをオン | 🟠 非表示 | 280 / 297 MB | 3.0% / 38% | 0.25% | 16枚 | 16枚 |
| スクリーンショット・常時OCRともにオフ（初期設定） | 🟢 表示 | 145 / 152 MB | 2.0% / 9% | 0 | 0 | 0 |
| スクリーンショットのみオン | 🟢 表示 | 145 / 155 MB | 3.5% / 31% | 0 | 16枚 | 0 |
| スクリーンショットと常時OCRをオン | 🟢 表示 | 400 / 405 MB | 4.1% / 31% | 0.23% | 16枚 | 16枚 |

> 1. 最大値は2秒ごとのサンプルのうち最も高い値です。
> 2. 撮影数と認識数は、5分間の測定中に撮影したスクリーンショットの枚数と、文字認識を行った枚数です。

#### プロセス別

| プロセス | 動作する条件 | メモリ平均（最大） | CPU平均 |
| --- | --- | --- | --- |
| Hindsightメインプロセス | 常時 | 約17 MB（28 MB） | スクリーンショット有効時1.8～2.4%、無効時約0.3% |
| 文字認識プロセス | 常時OCRが有効なとき | 約255 MB（270 MB） | 0.9～1.0% |
| メインウィンドウのWebプロセス（計7個） | 常時 | 表示中127～129 MB（137 MB）、非表示時7～9 MB（12 MB） | 表示中1.3～1.7%、非表示時ほぼ0 |

> 1. Webプロセスは、メインウィンドウの表示に使われるシステムのWebView2プロセスです。
> 2. 文字認識プロセスには、約2.3 GBのコミット サイズも確保されています（タスク マネージャーの「詳細」タブ）。その大部分は物理メモリを実際には使用していません。

#### 短時間のピーク

| 処理 | CPUピーク |
| --- | --- |
| スクリーンショットを1枚撮影 | メインプロセスで約21～34% |
| スクリーンショット1枚を文字認識 | 文字認識プロセスで約30～38% |

> ピーク値は2秒間の平均です。瞬間的な値はより高く、継続時間はより短くなることがあります。
