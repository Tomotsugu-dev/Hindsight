## 機能概要

指定したアプリ・ウィンドウ・ウェブページをスクリーンショットの対象から除外できます。「設定 → プライバシー」で設定します。

## プライバシーフィルター

キーワードを追加すると、一致するウィンドウやページは撮影されません。

- **アプリフィルター**：アプリ名やウィンドウタイトルにキーワードが含まれると、撮影しません。
- **ブラウザフィルター**：アドレスバーの URL にキーワードが含まれると、撮影しません。
- **ウェブサイトのドメインを記録**：アクセスしたサイト（`github.com` など）だけを記録し、個別のページは記録しません。例えば `https://github.com/xxx/issues/1` を開くと、`github.com` だけが保存されます。

## 初期設定

| 項目 | 初期設定 | 説明 |
| --- | --- | --- |
| スクリーンショットを有効化 | オフ | 「設定 → 一般」で有効化が必要 |
| ブラウザフィルター | ログイン関連のキーワード 10 件 | `/login`、`/signin`、`/auth`、`/oauth`、`/password` など。追加・削除可能 |
| アプリフィルター | 空 | - |
| ウェブサイトのドメインを記録 | オン | - |
