## 功能概述

隐私设置可以让指定的应用、窗口和网页不被截图。入口是「设置 → 隐私」。

## 隐私过滤

添加关键词后，匹配的窗口和网页不会被截图。

- **应用过滤**：应用名或窗口标题包含关键词时，不截图。
- **浏览器过滤**：浏览器地址栏的网址包含关键词时，不截图。
- **记录网站域名**：只记录你访问的网站（如 `github.com`），不记录具体打开了哪个页面。例如打开 `https://github.com/xxx/issues/1`，只会记下 `github.com`。

## 默认行为

| 项目 | 默认 | 说明 |
| --- | --- | --- |
| 截图 | 关闭 | 需要在「设置 → 常规」中主动开启 |
| 浏览器过滤 | 10 条登录相关关键词 | 如 `/login`、`/signin`、`/auth`、`/oauth`、`/password`，可以增删 |
| 应用过滤 | 空 | - |
| 记录网站域名 | 开启 | - |
