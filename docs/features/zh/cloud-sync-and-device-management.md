## 概述

Hindsight 支持通过云同步在多台设备间共享：活动记录、应用设置等数据，为跨平台，跨设备用户整合出完整的电脑活动使用记录。

## 支持的协议

Hindsight 目前支持以下云同步协议：

- **WebDAV**：通过 WebDAV 服务器进行数据同步，适用于自建或第三方提供的 WebDAV 服务（例如 Nextcloud、坚果云 等）。
- **Google Drive**：通过谷歌云端硬盘进行数据同步，适用于拥有 Google 账号的用户。

## 数据同步内容

| 数据 | 是否同步 | 说明 |
| --- | --- | --- |
| 活动记录（应用、窗口标题、时间、网站域名） | ✅同步 | - |
| 应用设置（应用分类规则、网站分类规则） | ✅同步 | - |
| AI 总结、聊天历史、屏幕记忆全文 | ⚙️可选 | 需在设置中分别单独开启 |
| 截图图片 | ❌不同步 | 永远仅留在本机 |

## 默认行为

| 项目 | 默认 | 说明 |
| --- | --- | --- |
| 云同步 | 关闭 | 需要主动配置 |
| 同步周期 | 约 5 分钟 | 后台每 300 秒自动上传与拉取一次，也可手动「立即同步」 |
| AI 总结文本 | 关闭 | 开启「AI 总结文本」后才同步 |
| 聊天历史 | 关闭 | 开启「聊天历史」后才同步 |
| 屏幕记忆全文 | 关闭 | 开启「屏幕记忆全文」后才同步识别出的文字 |
| 截图图片 | 不同步 | 永远仅留在本机 |
