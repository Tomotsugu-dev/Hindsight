## 功能概述

Hindsight 支持自定义数据的保留时间，支持数据导出为多种格式的统计文件，方便后续分析与统计。

## 数据导出

把每日、每周、每月的统计导出成文件。在「设置 → 数据 → 导出使用数据」中选择日期范围和格式。支持导出 HTML、Markdown、Excel 和 JSON 格式。

## 数据清理

- **自动清理**：截图超过保留时间后自动删除。活动记录和识别出的屏幕文字不会自动清理。
- **清空截图**：删除全部已保存的截图文件，活动记录和识别出的屏幕文字保留。
- **清空数据**：清空本机数据库里的活动记录、AI 总结、屏幕文字和聊天历史；应用设置（分类、应用分组和设置）保留。云端上的数据不受影响。
- **移除本设备**：清空本机数据并从云端移除本设备的记录，适用于不再使用该设备的情况。

## 默认行为

| 项目 | 默认 | 说明 |
| --- | --- | --- |
| 数据路径 | 系统应用数据目录下的 `Hindsight` 文件夹 | macOS 是 `~/Library/Application Support/Hindsight`，Windows 是 `%APPDATA%\Hindsight` |
| 截图路径 | 数据路径下的 `screenshots` 文件夹 | - |
| AI 模型路径 | 数据路径下的 `ai/models` 文件夹 | - |
| 截图保留 | 7 天 | 可设为 1–120 天，到期自动删除截图文件 |
| 活动记录保留 | 永久 | 不会自动清理 |
