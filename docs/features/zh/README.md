<h1 align="center">Hindsight 功能&特性</h1>

<p align="center">
  <a href="https://hindsight.kyosweb.com">官网</a> ·
  <a href="https://github.com/Tomotsugu-dev/Hindsight/releases/latest">下载</a> ·
  <a href="https://github.com/Tomotsugu-dev/Hindsight">GitHub</a>
</p>

Hindsight 是一个电脑使用情况记录工具：会在后台记录你使用的应用和窗口，生成日、周、月统计，并可选择用截图进行文字检索、AI 总结、基于 AI 的活动检索和多设备同步。
