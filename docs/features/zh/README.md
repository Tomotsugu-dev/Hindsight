## 开始使用

首次使用时，可以先让 Hindsight 在后台运行一段时间，再打开「日统计」查看应用和分类排行。基础统计不需要配置 AI 或登录云服务。

想进一步整理记录，可以依次完成下面几步：

1. 在「分类 → 归类应用」中，把常用应用分到适合自己的分类。
2. 在「设置 → 常规」中检查闲置阈值和工作时段，使记录范围符合自己的使用习惯。
3. 需要回看屏幕内容时，开启截图，并选择手动、定时或常驻文字识别。
4. 需要生成报告或用自然语言查询记录时，配置本地模型或云端 API。
5. 有多台电脑时，在各设备连接同一个同步服务和账号。

### 默认行为

下表描述新配置的默认值。升级用户保留的设置可能不同，以应用内显示为准。

| 项目 | 默认状态 |
| --- | --- |
| 活动采集 | 开启 |
| 截图 | 关闭 |
| 采集间隔 | 30 秒 |
| 闲置阈值 | 3 分钟 |
| 限定工作时段 | 关闭 |
| 记录浏览器网站域名 | 开启，实际记录取决于浏览器支持、权限及隐私过滤 |
| 截图保留时间 | 7 天 |
| 常驻 OCR、定时 OCR | 关闭 |
| AI 自动总结、云端 API | 关闭 |
| 云同步 | 需要用户主动连接 |
| AI 总结、聊天历史、屏幕记忆全文同步 | 分别关闭 |
| 开机自动启动 | 关闭 |
| 关闭窗口后保留后台运行 | 开启 |
| 自动检查更新 | 开启，每周检查 |

## 分类与应用管理

**入口：分类 → 管理分类／归类应用／归类网站。**

### 大类与小类

小类用于标记具体活动类型，例如编程、办公、影音（界面上叫「分类」）；大类用于把多个小类汇总到更大的用途，例如工作、娱乐。

在「管理分类」中，可以新建小类或大类、修改名称、颜色和图标，并通过拖动调整排序或归属。

- 删除小类后，其下应用回到「其他」。
- 删除大类后，原有小类回到「未归入大类」，小类本身保留。
- 修改分类是重新组织统计，不会因此删除原始活动记录。

### 归类应用与跨设备配对

「归类应用」列出已记录的应用。可以按应用名或进程名搜索，按分类筛选，或按名称、使用时长排序，再为应用指派分类。

同一个应用在不同系统上可能使用不同名称。多设备配对允许把这些条目合并到同一行，统一显示名称和分类，并合计使用时长。

例如，两台设备上的同一款编辑器被识别为不同条目时，可以在设备列中上下拖动，将它们放到同一行。配对错误时，可以把成员从组中移出，恢复为独立条目。

### 归类网站

「归类网站」允许给浏览器中的不同网站单独指定分类。例如，同一个浏览器里的开发文档可以归到工作，视频网站可以归到娱乐。

页面提供网站搜索、近 30 天与全部用时，以及子域名展开。网站列表来自已经记录到的域名；没有开启域名记录或尚未采集到域名时，列表可能为空。

分类遵循以下关系：

1. 网站有自己的分类规则时，使用该规则。
2. 子域名没有单独规则时，沿用已设置的母域名规则。
3. 没有匹配的网站规则时，沿用浏览器应用的分类。

例如，为 `example.com` 设置分类后，未单独设置的 `docs.example.com` 会沿用它。取消规则后，网站重新使用继承或浏览器分类。规则变化也会反映到已有域名记录的统计中。当前网站规则适用于所有浏览器，并可通过云同步共享到其他设备。

### 隐藏、忽略与删除

这些操作解决的问题不同，选择前应先确认希望保留哪些记录。

| 操作 | 适用情况 | 对数据的影响 |
| --- | --- | --- |
| 隐藏应用 | 暂时不把某应用计入统计 | 将应用归入「隐藏」，历史数据保留，恢复分类后可重新查看 |
| 忽略窗口 | 只排除某应用中的特定窗口用时 | 保留活动、截图和 OCR，仅从统计及相关分析中排除匹配记录 |
| 删除应用数据 | 清理某应用在本机保存的记录 | 删除对应活动、截图及文字索引；已有报告和聊天内容不随之清除 |

在应用详情的窗口标题旁，可以使用「从统计中忽略此窗口」。在「分类 → 归类应用 → 已忽略的窗口」中可以移除规则，恢复相关历史记录的统计。忽略规则仅本机生效。

隐藏属于分类设置，启用云同步后会同步到其他设备。浏览器有网站分类规则时，对应网站使用自己的有效分类；仅修改浏览器的分类未必覆盖这些网站。截图过滤、窗口忽略和隐藏分类都不能用作“这个应用的数据不上传”的开关。

删除应用数据后，该程序再次被采集时仍会重新出现。当前的应用数据删除作用于本机，云端和其他设备可能仍有记录；不要把它当作跨设备彻底删除。

## 屏幕记忆与搜索

**入口：全部历史 → 搜索；设置 → 常规 → 采集。**

屏幕记忆通过 OCR（文字识别）把截图中的文字建立为本地索引。你可以搜索曾经读过的一句话、文档中的关键词或页面上的文字，再定位到当时的时间和截图。

### 开启与建立索引

1. 在「设置 → 常规」中开启「启用截图」，按系统提示授予所需权限。
2. 选择下面任意一种文字识别方式。
3. 等待截图完成识别后，到「全部历史 → 搜索」输入关键词。

| 方式 | 入口 | 行为 |
| --- | --- | --- |
| 手动回填 | 设置 → 常规 → 回填历史截图；对话页的「立即回填」提示 | 登记并识别尚未进入索引的历史截图 |
| 自动 OCR | AI 设置 → 常规 → 定时计划 | 在指定时间批量识别积压截图 |
| 常驻 OCR | 设置 → 常规 → 常驻 OCR | 后台持续处理新截图，更快地让内容可以被搜索 |

macOS 使用系统原生文字识别。Windows 需要 OCR 组件，缺失时应用会提示下载，也可以在「AI 设置 → 引擎」中管理。

常驻 OCR 会增加内存占用，在检测到电池供电时暂停常驻处理，接回电源后继续。手动和定时识别可以独立使用，定时任务需要 Hindsight 正在运行。

### 搜索与查看结果

输入关键词后，页面自动搜索文字索引，显示匹配片段、相关应用和时间。点击结果可以查看对应截图，并进行放大、缩小或重置缩放。

搜索使用已经识别出的文字，不需要配置大语言模型。截图尚未识别、当时没有截图、文字过小或识别错误，都可能导致搜索不到。可以更换关键词，或先完成历史截图回填。

### 截图与文字的保留范围

截图文件和 OCR 文字分别保存。截图超过保留时间或被手动清理后，已识别的文字仍可能被搜索到，页面会提示截图已被清理，并显示文字内容。

因此：

- 清空截图不会同时清空文字索引。
- 截图文件已经删除且此前未完成识别时，无法再从该图片补识别。
- OCR 适合查找文字，不能保证理解照片、图表或视频中的纯视觉内容。
- 只会识别实际保存下来的截图，无法还原未被捕获的画面。

需要同时处理文字、聊天或其他历史数据时，查看[清理本机数据](#清理本机数据)。

## AI 总结与对话

**入口：AI 总结、对话。使用前先完成 [AI 配置](#ai-配置)。**

### 日报

在「AI 总结 → 日报」选择日期并点击「开始总结」，Hindsight 会按照配置的时段，将当天的活动记录整理成文字报告。

日报使用应用、窗口标题、分类和时间线等信息生成，无需提前开启截图。没有活动记录或没有符合分析范围的内容时，相应时段会跳过。

页面支持：

- 查看各时段的报告和生成状态。
- 停止当前生成任务。
- 重试某个时段，或重新生成整天报告。
- 删除当天的日报。
- 将报告导出为 Markdown。

重新生成会更新相应报告；需要保留旧内容时，可以先导出。删除日报只处理报告本身，原始活动记录继续保留。

### 周报

在「AI 总结 → 周报」选择一周并开始生成。周报优先使用这一周已有的日报，整理成整周回顾。

部分日期缺少日报时，界面会提示缺失情况；选择继续后，缺失日期使用应用统计作为补充，报告细节会更少。先补齐日报通常能得到更完整的周报。

周报也支持停止、重新生成、删除和导出 Markdown。删除周报不会删除日报。

当前「月报」页面仍为开发中的占位入口，尚不能生成 AI 月报。「月统计」可以正常使用。

### 自动总结

在「AI 设置 → 常规 → 定时计划」开启「自动总结」，并设置处理时间。首次开启时默认安排在 `23:00`，可以修改并添加多个时间点，最多 6 个。

每个时间点可以生成或刷新当天日报。例如，中午生成半天回顾，晚上再更新为全天回顾。后台还会检查前一天未补齐的日报，以及上一完整周的周报。

自动总结需要应用保持运行，且模型已经配置可用。睡眠、退出应用、模型未就绪或已有任务运行，都可能使执行延后。自动任务不保证无限重试；失败后可以检查配置，再从日报或周报页面手动重试。

自动总结与自动 OCR 分别控制。活动时间线可以直接用于报告；只有想搜索屏幕文字时，才需要先完成对应截图的识别。

### 基于历史记录的对话

在「对话」页可以用自然语言查询自己的记录，例如：

- “上周我在编辑器里花了多少时间？”
- “昨天下午主要在做什么？”
- “我什么时候看过包含这个关键词的页面？”

对话可以查询使用统计、检索已识别的屏幕文字，并查看相关时间线。回答附有来源时，可以展开来源查看依据。

会话支持新建、重命名和删除；提问可以编辑并形成新的对话分支，回答可以重试、复制，并在已有分支或回答版本之间切换。会话保存在本机，重新打开应用后可以继续查看。

页面顶部显示当前使用的模型，可选择可用的本地或云端模型。支持的模型还可以调整思考模式；较高强度可能增加等待时间和服务商的计费消耗。

本地对话需要支持工具调用的模型。不支持工具调用的本地模型不会出现在可选列表中，但可能仍可用于生成总结。

### AI 能知道什么

AI 的回答取决于实际记录、识别结果和查询范围。关闭截图不影响基于活动用时的提问，但未进入文字索引的页面内容无法通过屏幕记忆检索。

报告和回答可能出现遗漏或错误；涉及具体时间、名称或内容时，可以结合统计页面和引用来源核对。

使用云端模型时，提问和生成报告所需的文本会发送到所选服务商。截图图片本体不通过这条功能上传，但检索命中的 OCR 文字仍可能包含截图中的敏感内容。首次发送对话前，应用会展示当前模型与数据发送范围。

### 调试入口

「AI 总结 → 调试」目前支持日报调试，可以检查生成过程、重新生成调试报告、导出 Markdown 或删除调试结果。调试结果与常规日报分开保存；周报和月报的调试尚未实现。

## AI 配置

**入口：AI 设置 → 引擎／模型／常规／提示词／云端 API。**

### 使用本地模型

1. 在「引擎」页下载本地 AI 引擎。
2. 在「模型」页选择并下载模型，或导入已有的 GGUF 模型文件。
3. 为文本总结选择模型；需要对话时，在对话页选择支持工具调用的模型。
4. 使用测试连接确认引擎可用，再生成一份日报或发送提问。

本地推理在电脑上进行，速度和可使用的模型大小取决于处理器、显卡以及可用内存。模型下载需要联网；运行时也要确保有足够存储和内存。

引擎页可以查看安装与运行状态、下载或更新引擎、测试连接、打开安装目录，以及停止引擎释放显存。卸载引擎不会同时删除模型文件。

### 选择下载源

在「AI 设置 → 引擎」的「下载源」中，可以选择官方源、预设镜像或自定义镜像。该设置用于模型、AI 引擎、OCR 运行时，以及 OCR 模型和字典的下载。模型页也提供更改下载源的入口。

预设镜像使用第三方提供的 HF-Mirror、GH-Proxy，以及用于 Windows OCR 组件的华为云 NuGet 镜像。自定义时，分别填写 Hugging Face 镜像的基础地址、GitHub 下载代理的地址和 NuGet 包下载地址；GitHub 代理需支持在地址后追加完整下载链接。

更改只影响之后开始的下载。模型暂停后再继续，会使用当前下载源尝试续传；服务器不支持续传时会从头下载。

### 管理模型

模型页提供名称、大小和能力等信息，并支持按状态、大小或类型查找模型。

- 下载可以暂停并继续。
- 支持从 Hugging Face 仓库填写文件信息下载自定义 GGUF 模型。
- 支持把已有 GGUF 文件导入到模型目录。
- 可以卸载不再使用的模型，释放磁盘空间。

导入文件必须能被当前引擎加载。视觉投影文件不能单独作为模型使用。模型的能力标签也不代表 Hindsight 的所有功能都会调用该能力；当前报告与对话主要使用文本材料。

### 使用云端 API

在「云端 API」页开启服务，选择服务商，填写服务地址、API Key 和模型 ID，然后测试连接。支持页面列出的服务商预设，也可以配置兼容接口的自定义服务。

可以从服务端读取可用模型，并将常用配置保存为多组，便于切换。

配置云端服务后，应分别确认使用位置：

- **总结**：在「模型」页选择云端文本模型作为总结模型。
- **对话**：在对话页的模型选择器中确认当前模型。未显式指定本地模型时，完整可用的云端配置可能被自动选用。

云端调用使用你自己的服务商账号，可能产生费用。API Key 保存在本机设置中，当前为明文存储；共享数据目录或备份前，应检查其中是否包含密钥。

### 时段、分析范围与提示词

在「常规」页设置一天的总结时段，并选择参与 AI 分析的分类。这些设置决定报告使用哪些活动材料，不会停止相应活动的采集。

在「提示词」页可以调整报告的写法，例如希望更关注项目进展、减少泛泛评价，或使用特定组织方式。修改提示词后需要保存；重置会恢复默认内容，也需要保存后生效。

可以填写个人简介，帮助模型理解自己的工作背景。该信息会用于总结上下文；使用云端总结时，也应把它视为会发送给服务商的内容。

界面语言切换会同步调整报告使用的提示词语言。自定义提示词按语言分别保存。

### 引擎参数

引擎页提供上下文长度、批大小和并发等参数，以及资源占用估算或推荐设置。较大参数可能增加内存或显存占用。修改启动参数后，需要让引擎重新启动才会使用新值。

不了解这些参数时，可以先使用推荐设置，从较小模型验证完整流程。

## 云同步与设备管理

**入口：侧栏「云同步」，或侧栏顶部的账号状态。**

云同步将不同电脑的活动记录汇总到本机，便于在一个界面查看多设备使用情况。可选择 Google Drive 或 WebDAV，同一时间使用一个同步服务。

### 同步哪些内容

| 数据 | 同步方式 |
| --- | --- |
| 活动记录 | 连接同步后参与同步，包含应用、窗口标题、时间及已记录的网站域名 |
| 小类、网站分类规则、应用配对和设备信息 | 作为基础数据同步；大类以及小类归在哪个大类暂不同步 |
| AI 总结文本 | 单独开启「AI 总结文本」后同步 |
| 对话会话与消息 | 单独开启「聊天历史」后同步 |
| OCR 屏幕文字 | 单独开启「屏幕记忆全文」后同步 |
| 截图图片本体 | 不同步 |

可选数据集的开关同时控制上传和接收，需要在希望使用相应数据的设备上开启。关闭开关不会自动删除此前已经上传或下载的副本。

跨设备同步屏幕文字后，可以检索文字，但原始截图仍只保留在拍摄它的设备上。

### 连接 Google Drive

1. 在「云同步」中选择 Google Drive。
2. 点击「用 Google 登录」，在浏览器完成授权。
3. 返回应用，检查连接状态，并等待首次同步或点击「立即同步」。

如果当前安装包没有可用的 OAuth 配置，按页面内的「配置 OAuth」说明填写客户端信息。浏览器没有自动打开时，可以复制登录链接继续授权。

数据存放在所连接 Google Drive 的应用数据区。其他电脑连接同一个账号后，才能互相同步。

### 连接 WebDAV

1. 选择 WebDAV，填写 HTTPS 服务器地址、用户名和应用密码。
2. 点击「连接」，等待验证成功。
3. 在其他设备填写同一服务器和账号。

适用于提供 WebDAV 的网盘或自建服务，例如坚果云、Nextcloud。需要应用密码的服务，应使用该服务生成的应用密码。

同一账号更新密码时，可以使用「改凭证」。服务器访问限制、凭证过期或空间不足时，页面会显示对应状态。

### 同步状态与账号切换

连接成功后，应用会在后台周期性同步，目前默认周期约 5 分钟。也可以点击「立即同步」，查看待发送数量、最近同步时间和失败状态。网络或云端服务异常可能使同步延后。

退出账号会停止使用当前凭证同步，已经保存在本机和云端的数据继续保留。

更换同步服务或账号后，本设备的记录会重新上传到新位置。其他设备也需要连接到相同位置，才能继续互相同步；原服务中的数据不会因切换而自动删除。

### 设备管理

设备页显示本机和已同步的其他设备，可以修改本机名称、颜色和图标。给设备设置容易辨认的名字，有助于在统计页面选择数据来源。

当前使用 Google Drive 时，可以从其他设备卡片移除已不再使用的远端设备。该操作会删除目标设备的云端文件，并通知其他设备在后续同步时清理对应记录。

移除本机的入口在「设置 → 数据 → 移除本设备」。操作会退出当前同步账号，并允许选择是否保留本机副本。当前 WebDAV 不支持应用内的云端设备移除操作。

### 同步与 AI 的关系

云同步和云端 AI 分别配置：连接云盘不代表开启云端 AI，配置云端 AI 也不代表开启多设备同步。

基础同步包含窗口标题等活动信息。当前没有按应用单独禁止上传的开关；隐私截图过滤、隐藏分类和忽略窗口不会阻止活动数据同步。

## 设置与数据管理

### 隐私过滤

**入口：设置 → 隐私。**

支持两类不区分大小写的关键词匹配：

- **URL 关键词**：浏览器地址包含关键词时跳过截图。默认包含部分常见登录和认证路径，可自行增删。
- **标题／应用关键词**：应用名称或窗口标题包含关键词时跳过截图。

匹配隐私过滤的浏览器活动也不会写入网站域名。活动记录、窗口标题和使用时长仍可能保留；这不是停止记录整个应用的功能。

设置了 URL 过滤关键词时，如果浏览器地址暂时读取不到，应用会跳过这次浏览器截图，避免在无法判断页面内容时保存画面。

过滤规则仅在本机生效，并且只影响之后的采集。添加关键词不会删除已有截图、OCR 文字、报告或云端数据。

### 文件保存位置与保留时间

**入口：设置 → 常规、设置 → 数据。**

| 设置 | 作用与注意事项 |
| --- | --- |
| 数据保存路径 | 存放数据库等应用数据；修改后需要重启，旧数据需要手动迁移 |
| 截图保存路径 | 指定截图存放位置；更改位置不等于移动已有截图 |
| AI 模型保存路径 | 指定模型目录；旧模型不会自动迁移，需要手动复制或重新下载 |
| 截图保留 | 默认 7 天，界面可设置 1～120 天；到期自动删除截图文件 |

「设置 → 数据」会显示活动记录、屏幕文字和截图的存储占用。截图保留时间不用于自动清理活动记录、OCR 文字或聊天历史。

需要迁移数据目录时，应先退出应用并保留旧目录副本，再按应用提示复制数据和重启。

### 导出使用数据

**入口：设置 → 数据 → 导出使用数据；统计页面的导出按钮。**

选择日期范围，可以使用今天、本周、本月、今年、全部等快捷范围，或手动指定开始和结束日期。应用根据跨度自动选择日、周、月统计，弹窗会显示即将包含的内容。

| 格式 | 适合的用途 | 包含内容 |
| --- | --- | --- |
| HTML | 直接阅读或分享报告 | 带图表和配色的单个网页文件，可离线打开 |
| Markdown | 放进笔记或继续编辑 | 可读的统计报告，应用排行保留主要条目 |
| Excel | 筛选、排序和进一步分析 | 概览、趋势及活动明细等工作表 |
| JSON | 程序读取或后续处理 | 结构化统计数据 |

当前使用数据导出汇总全部设备，并不自动沿用统计页的设备筛选。周、月汇总按完整自然周和自然月计算，边界可能超出所选日期范围，以报告标注的周期为准。

Excel 的活动明细包含日期、开始时间、时长、应用、窗口标题、分类和设备。明细按所选日期范围导出，并排除统计中已隐藏或忽略的记录；最多保留 100 万行，超过时会在表内说明。

这些导出文件不是完整数据库备份，也不包含截图文件。日报和周报的 Markdown 导出位于各自的 AI 总结页面。

### 清理本机数据

**入口：设置 → 数据 → 本地数据清理。**

| 操作 | 删除内容 | 保留内容 |
| --- | --- | --- |
| 清空截图 | 当前截图目录中的截图文件 | 活动记录、已识别的文字、AI 总结与聊天历史 |
| 清空数据 | 本机数据库中的活动记录、AI 总结、屏幕文字索引和聊天历史等 | 分类、应用分组、设备、设置及登录状态；截图文件需另行清理 |

这里的“本机数据库”也包括此前从其他设备同步到本机的副本。清空本机数据不会直接删除云端或其他设备的数据，也不会自动从云端恢复全部旧记录。继续开启采集时，之后仍会产生新记录。

如果目标是同时清理本机活动与截图，需要分别执行对应操作。若还需要处理云端副本，应按[云同步与设备管理](#云同步与设备管理)中的设备移除说明操作，并确认所用同步服务的支持范围。

### 语言、外观与启动行为

- **语言**：在「设置 → 常规」选择简体中文、繁体中文、英语、日语、葡萄牙语或西班牙语。
- **外观**：在「设置 → 外观」选择明亮、简约或暗色主题，设置在本机生效。
- **自动启动**：控制登录操作系统后是否运行 Hindsight，以及启动时是否显示主窗口。
- **关闭窗口**：控制关闭主窗口后继续在后台运行，还是退出应用。

### 版本与更新

「设置 → 关于」显示当前版本，并提供检查更新、项目仓库和问题反馈入口。可以开启或关闭自动检查，并选择每天、每周、每月或每次启动检查。

自动检查更新会联网；发现更新后，按应用提示下载安装。

## 常见问题

### 只想统计时间，需要开启截图或 AI 吗？

不需要。活动记录和日／周／月统计可以独立使用。截图用于保留画面，OCR 用于搜索文字，AI 用于生成报告和自然语言查询。

### 为什么有使用时长，却没有截图？

先检查是否开启截图，以及系统权限、隐私过滤和截图保留时间。活动记录与截图分别处理，因此有用时记录并不保证一定能看到对应图片。

### 为什么搜索不到刚刚看过的内容？

只有已经截图并完成 OCR 的文字能被搜索。短暂出现的内容可能错过采样，也可能尚未识别或识别不准确。可以在对话页查看待识别提示，或手动回填历史截图。

### 为什么删除截图后还能搜到文字？

已经识别出的文字单独保存在屏幕记忆中。删除图片不删除这份文字；需要清理文字时，应检查本机数据和可选云同步副本。

### 隐藏应用能保护它不被截图或上传吗？

隐藏主要改变统计展示。需要避免截图时配置隐私过滤；需要停止新增活动记录时暂停采集。当前同步没有按应用禁止上传的选项。

### 多台设备同时使用时，统计会合并成一份工时吗？

全部设备视图汇总各设备的记录，重叠使用时间可能相加。需要了解单台电脑的使用情况时，应切换设备筛选。

### 不使用云同步，云端 AI 还能用吗？

可以。两者独立配置。云端 AI 会把本次请求所需的文本发送给模型服务商；云同步则将选定数据存入所连接的云盘。

### 为什么没有 AI 月报？

当前月报入口仍在开发中。可以先使用月统计查看趋势，并用对话查询相应月份的活动记录。
