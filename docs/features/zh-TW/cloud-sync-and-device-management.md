## 概述

Hindsight 可透過雲同步在多台裝置間共享活動記錄、應用程式設定等資料，為跨平台、跨裝置使用者整合完整的電腦活動記錄。

## 支援的協定

Hindsight 目前支援以下雲同步協定：

- **WebDAV**：透過 WebDAV 伺服器同步資料，適用於自架或第三方 WebDAV 服務（例如 Nextcloud、堅果雲等）。
- **Google Drive**：透過 Google 雲端硬碟同步資料，適用於擁有 Google 帳號的使用者。

## 資料同步內容

| 資料 | 是否同步 | 說明 |
| --- | --- | --- |
| 活動記錄（應用程式、視窗標題、時間、網站網域） | ✅同步 | - |
| 應用程式設定（應用程式分類規則、網站分類規則） | ✅同步 | - |
| AI 總結、聊天歷史、螢幕記憶全文 | ⚙️可選 | 需在設定中分別開啟 |
| 截圖圖片 | ❌不同步 | 永遠只留在本機 |

## 預設行為

| 項目 | 預設 | 說明 |
| --- | --- | --- |
| 雲同步 | 關閉 | 需自行設定 |
| 同步週期 | 約 5 分鐘 | 背景每 300 秒自動上傳與下載一次，也可手動「立即同步」 |
| AI 總結文字 | 關閉 | 開啟「AI 總結文字」後才同步 |
| 聊天歷史 | 關閉 | 開啟「聊天歷史」後才同步 |
| 螢幕記憶全文 | 關閉 | 開啟「螢幕記憶全文」後才同步辨識出的文字 |
| 截圖圖片 | 不同步 | 永遠只留在本機 |
