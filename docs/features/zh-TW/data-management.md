## 功能概述

Hindsight 支援自訂資料保留時間，也可將資料匯出為多種格式的統計檔案，方便後續分析與統計。

## 資料匯出

將每日、每週、每月統計匯出成檔案。在「設定 → 資料 → 匯出使用資料」選擇日期範圍與格式，支援 HTML、Markdown、Excel 和 JSON 格式。

## 資料清理

- **自動清理**：截圖超過保留時間後自動刪除。活動記錄和辨識出的螢幕文字不會自動清理。
- **清空截圖**：刪除所有已儲存的截圖檔案，保留活動記錄和辨識出的螢幕文字。
- **清空資料**：清空本機資料庫中的活動記錄、AI 總結、螢幕文字與聊天歷史；保留應用程式設定（分類、應用程式分組和設定）。雲端資料不受影響。
- **移除本裝置**：清空本機資料，並從雲端移除本裝置的記錄，適用於不再使用該裝置的情況。

## 預設行為

| 項目 | 預設 | 說明 |
| --- | --- | --- |
| 資料路徑 | 系統應用程式資料目錄中的 `Hindsight` 資料夾 | macOS 為 `~/Library/Application Support/Hindsight`，Windows 為 `%APPDATA%\Hindsight` |
| 截圖路徑 | 資料路徑中的 `screenshots` 資料夾 | - |
| AI 模型路徑 | 資料路徑中的 `ai/models` 資料夾 | - |
| 截圖保留 | 7 天 | 可設為 1–120 天，到期自動刪除截圖檔案 |
| 活動記錄保留 | 永久 | 不會自動清理 |
