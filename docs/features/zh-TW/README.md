<h1 align="center">Hindsight 完整功能說明</h1>

<p align="center">
  <a href="https://hindsight.kyosweb.com">官方網站</a> ·
  <a href="https://github.com/Tomotsugu-dev/Hindsight/releases/latest">下載</a> ·

</p>

Hindsight 是一款電腦使用情況記錄工具：在背景記錄你使用的應用程式和視窗，產生日、週、月統計，也可選擇透過截圖進行文字搜尋、AI 總結、AI 活動搜尋及多裝置同步。
