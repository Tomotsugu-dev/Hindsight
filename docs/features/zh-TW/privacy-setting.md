## 功能概述

隱私設定可讓指定的應用程式、視窗和網頁不被截圖。入口為「設定 → 隱私」。

## 隱私過濾

新增關鍵字後，符合條件的視窗和網頁不會被截圖。

- **應用程式過濾**：應用程式名稱或視窗標題包含關鍵字時，不截圖。
- **瀏覽器過濾**：瀏覽器位址列的網址包含關鍵字時，不截圖。
- **記錄瀏覽器網站網域**：只記錄造訪的網站（如 `github.com`），不記錄開啟的特定頁面。例如開啟 `https://github.com/xxx/issues/1`，只會記下 `github.com`。

## 預設行為

| 項目 | 預設 | 說明 |
| --- | --- | --- |
| 截圖 | 關閉 | 需自行在「設定 → 常規」開啟 |
| 瀏覽器過濾 | 10 條登入相關關鍵字 | 如 `/login`、`/signin`、`/auth`、`/oauth`、`/password`，可新增或刪除 |
| 應用程式過濾 | 空白 | - |
| 記錄瀏覽器網站網域 | 開啟 | - |
