<h1 align="center">Hindsight Feature Reference</h1>

<p align="center">
  <a href="https://hindsight.kyosweb.com">Website</a> ·
  <a href="https://github.com/Tomotsugu-dev/Hindsight/releases/latest">Download</a> ·

Hindsight tracks computer usage: it records the apps and windows you use in the background and generates daily, weekly, and monthly statistics. Optional features include screenshot text search, AI summaries, AI-based activity search, and sync across devices.
