# Security Policy

## Reporting a vulnerability

Please do not open a public issue.

Report it privately on GitHub instead: open the **Security** tab of this repository and click **Report a vulnerability**, or go to
https://github.com/Tomotsugu-dev/Hindsight/security/advisories/new

Please include what you found, how to reproduce it, and the Hindsight version you used.

## Supported versions

Only the latest release gets security fixes.
